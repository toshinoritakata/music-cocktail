# 公開前ライセンス確認

確認日: 2026-09-21。対象: Sound & SipのGitリポジトリ公開。商用サービス、モデル改変、依存ライブラリ入りバイナリ配布の全面的な適法性を保証するものではない。

## 結果と対応

- アプリ本体にはライセンスがなかった。Essentia.jsとの組合せを考慮して独自コード・文書・合成サンプルをAGPL-3.0-onlyとし、全文と適用範囲を追加。UIにソースとライセンスへのリンク、無保証表示を追加。
- npm依存70件の宣言をpackage-lockから確認。AGPL、Apache、MIT、ISC、BSD系。[一覧](dependency-licenses.md)。node_modulesやコンパイル済みEssentiaはGitに含めない。利用者がnpm ciで取得する。
- MSD MusiCNNは公式配布の未改変ファイル。元の著作権・ライセンス・メタデータを保持し、帰属先・原本リンク・変更なしを明記。
- MTG公式資料のSA/ND不一致を発見。前のREADMEの「SA」との断定を訂正。双方で許される帰属表示付き・未改変・非商用の再配布として扱い、商用利用や改変モデル配布はMTGへの確認が必要と明記。
- 音源は独自スクリプトの合成音のみ。画像はCSSで描画。CLMR/MERTの重みは含まない。TypeSafeのSDKやサービスを再配布せず、APIを呼び出すコードだけを含む。利用者のAPI利用には同サービスの条件が別途適用される。
- .envとnode_modulesは除外。公開前に全Git履歴のblobを、設定済みAPIキーおよび一般的な資格情報パターンに照合する。これは未知の秘密情報の完全検出を保証するものではない。

## 配布・運用時

AGPLは一律に商用禁止のライセンスではない。コードのソース提供等の義務と、モデル側の非商用条件は別の条件として扱う。モデル込みの現構成を商用利用可能とは案内しない。

改変版を配布・ネットワーク提供する場合は、その版に対応したソースと必要なビルド情報を提供する。公開リポジトリへのリンクだけで、異なるバイナリや将来の改変版の全義務が自動的に満たされるわけではない。

一次資料と正確な依存版のソースは [THIRD_PARTY.md](../THIRD_PARTY.md) に記載。
