# Sound & Sip

音楽の音響特徴・ジャンル・ムード・BPMから、Jevが20種類のハウスレシピを選ぶローカルWebアプリです。マイク、音声ファイル、内蔵サンプルに対応します。

## 起動

Node.js 22以降。

```sh
npm ci
cp .env.example .env
# .env の TYPESAFE_API_KEY をローカルで設定（省略するとデモモード）
npm start
```

[アプリを開く](http://127.0.0.1:4317)。既存の `.env` がある場合はコピーで上書きしないでください。キーはGit管理対象外で、ブラウザには送信しません。設定変更後はサーバーを再起動します。

## 使い方

- 音楽ファイルを選んで再生するか「サンプル音を再生」を押します。
- 「マイクで聴く」でブラウザの許可を与えると、OS/ブラウザの既定マイクを使用します。入力選択UIは未実装です。停止、入力切替、ページ離脱時にマイクを解放します。マイク音はスピーカーへ出しません。
- 音響特徴は約5秒後、音楽タグはモデル準備後に12秒の音が集まると表示します。タグは約6秒ごとに再解析します。
- 5秒ごとの提案更新を切り替えられます。初回・手動以外は同じ候補が2回続くと更新。「固定」で気に入った一杯を保持します。
- 「ノンアルコールのみ」は候補をAPI呼出前に6種類へ絞ります。
- `samples/` に動作確認用の合成WAVを3種類同梱しています。`python3 samples/generate.py` で再生成できます。

## 解析と役割分担

1. Web AudioでRMS、スペクトル重心、低音比を測定し、直近10秒を平均。
2. WorkerでMSD MusiCNNを実行し、ジャンル・曲の印象を推定。TensorFlow.js WASM、Essentiaの前処理、16kHz monoを使用。
3. Essentia RhythmExtractor2013でBPMを推定。拍が不明瞭な場合は未判定にします。
4. Nodeサーバーが入力を検証し、推定タグ・BPMと音響特徴、レシピ候補をTypeSafeのJev Choiceへ送信。既存レシピのIDを選びます。

タグの数字はモデルスコアであり、正答率ではありません。弱い候補は「弱」と表示し、Jevにも暫定値として渡します。ムードは曲の印象で、聴取者の心理状態ではありません。BPMには半分・倍の誤推定があり、音量・環境音にも影響されます。30秒以上古いタグは使用しません。

音声ファイル・マイクの生音声は端末内で解析し、外部送信・録音保存しません。Jevに送信するのは集約した特徴・推定タグ・BPM・レシピ候補・選択条件です。APIキーはサーバー側だけで使用します。

キー未設定時は3つの音響特徴によるルール選択です（音楽タグは選択に使いません）。APIエラー時にデモへ黙って切り替えることはありません。説明欄は選択時の測定値と登録済み情報の表示であり、Jevの推論説明ではありません。

## 検証

```sh
npm test
```

12件：入力と音楽タグの検証、Jevへの解析情報受渡し、ノンアルコール制約、マイク解放・権限競合、リサンプリングの帯域外抑制など。GitHub Actionsでも実行します。

ブラウザでは内蔵合成音からジャンル・ムード・約119 BPMを表示し、Jevの実APIによるレシピ選択まで確認しました。これは動作確認で、実音源による認識精度評価ではありません。
